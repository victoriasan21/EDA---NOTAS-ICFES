# Análisis Exploratorio del ICFES (EDA)

Este proyecto realiza un **Exploratory Data Analysis (EDA)** sobre los resultados del examen ICFES en Colombia, con el objetivo de identificar **factores sociodemográficos** que influyen en el rendimiento académico de los estudiantes.

---

##  Objetivos del proyecto
1. **Análisis univariado** del puntaje global para entender la distribución del rendimiento.
2. **Análisis bivariado y correlaciones** entre el puntaje global y variables sociodemográficas (ej. acceso a internet, computador, educación de los padres, características del colegio).
3. **Validación ética** de los resultados para garantizar neutralidad y evitar estigmatización de sectores.

---

## Estructura del proyecto
- `icfes.csv` → Dataset con resultados del ICFES (2011–2016).
- `EDA_ICFES.ipynb` → Notebook principal con el análisis paso a paso.
- `README.md` → Documento explicativo del proyecto.

---

## Tecnologías utilizadas
- **Python 3**
- **Pandas** para manipulación de datos
- **NumPy** para cálculos numéricos
- **Matplotlib** y **Seaborn** para visualización
- **Jupyter Notebook / Google Colab** como entorno de ejecución
